# 🍽️ Smart Restaurant Food Ordering & Kitchen Dashboard

A Django-based restaurant management web application that allows customers to browse food items, add items to a cart, place orders, and track order preparation through a kitchen dashboard.

## 🚀 Features

- Browse restaurant menu items with prices and images
- Add food items to cart and manage quantities
- Enter customer details and table number
- Place orders and calculate the total with 5% tax
- Store orders and order items in a database
- Display order confirmation and order number
- Kitchen dashboard with order statistics
- Update order status: Received, Preparing, Ready, Completed
- Admin-protected kitchen dashboard

## 🛠️ Technologies Used

- Python
- Django
- SQLite
- HTML5
- CSS3
- Bootstrap
- JavaScript

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install Django:

   `python -m pip install django`

4. Apply database migrations:

   `python manage.py migrate`

5. Start the development server:

   `python manage.py runserver`

6. Open `http://127.0.0.1:8000/` in your browser.

## 👨‍🍳 Kitchen Dashboard

Open `http://127.0.0.1:8000/kitchen/` to manage restaurant orders. A staff/admin account is required.

## 🎯 Project Objective

To simplify restaurant food ordering and kitchen operations by managing customer orders, order details, and preparation status in one application.
